# Application icon source

`app-icon-source.png` is the project-owned raster source for the application mark. `ClimbAndMaintain.Acars.ico` is the 256 × 256 Windows icon derived from it and embedded in both the WPF executable and NSIS installer.

The mark depicts an aircraft climbing to capture a level altitude. It uses the default `#005EA8` product accent and contains no third-party logo or trademark.
